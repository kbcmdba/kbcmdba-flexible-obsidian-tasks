# Flexible Tasks - demo

Open this note in **reading view** with the plugin enabled.

| Today        | This Week       | Someday          |
| :----------- | :-------------- | :--------------- |
| - [ ] One    | - [/] Draft PR  | - [ ] Learn Rust |
| - [x] Two    | - [ ] Review    | - [-] Old idea   |
| - [/] Three  | - [>] Deferred  | - [?] Maybe      |

Left-click a checkbox to complete it (done <-> to-do). Right-click to set any
status: To do, Done, In progress, Cancelled, Forwarded, Question, Important.

The status character always round-trips faithfully to the source - a `[/]` in
progress stays `[/]` unless you change it.
